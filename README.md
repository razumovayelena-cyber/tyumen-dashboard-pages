# Дашборд «Тюмень 440»

Статический интерактивный дашборд с результатами апробации Стандарта здоровой среды в Тюмени.

## Технологии

- HTML5
- CSS3
- JavaScript без сборщика
- Leaflet для карты
- Chart.js для графиков
- локальные библиотеки для формирования отчетов DOCX и PDF
- локальные шрифты Montserrat

## Структура

- `index.html` — точка входа;
- `css/` — стили;
- `js/` — логика дашборда, расчетная модель и экспорт отчетов;
- `img/` — изображения и логотипы;
- `fonts/` — локальные шрифты;
- `lib/` — локальные JavaScript-библиотеки и стили;
- `report/` — шаблон отчета DOCX.

Проект работает как статический сайт. Отдельная база данных и SQLite для публикации не требуются: расчетные данные находятся в JavaScript-модели дашборда.

## Локальный запуск

Для запуска нужен Python 3:

```bash
python serve.py
```

После запуска откройте:

<http://127.0.0.1:8765>

Альтернативный вариант:

```bash
python -m http.server 8765
```

Затем откройте <http://127.0.0.1:8765>.

## Production-проверка

У проекта нет `package.json`, поэтому команды `npm install`, `lint`, `typecheck` и `npm run build` не используются. Production-версией является содержимое этой папки, отдаваемое статическим веб-сервером.

Перед публикацией проверьте:

- открытие `index.html` через HTTP-сервер;
- загрузку карты, графиков и локальных библиотек;
- работу навигации и фильтров;
- формирование отчетов;
- отображение на desktop и mobile;
- отсутствие ошибок в консоли браузера.

## Публикация на Vercel Hobby

### Через Vercel Dashboard

1. Войдите в Vercel.
2. Выберите `Add New Project`.
3. Импортируйте GitHub-репозиторий.
4. Укажите `Other` или оставьте автоматическое определение, если Vercel распознает статический проект.
5. Оставьте Build Command пустой.
6. Укажите Output Directory как `.`, если Vercel запросит это поле.
7. Нажмите `Deploy`.
8. Проверьте production URL.

### Через Vercel CLI

```bash
npm install -g vercel
vercel login
vercel
vercel --prod
```

Для этого статического проекта дополнительные переменные окружения не требуются.

## Яндекс Метрика

Счетчик Яндекс Метрики установлен в `index.html`. Используется счетчик
`112546302`.

Статистика доступна в кабинете [Яндекс Метрики](https://metrika.yandex.ru/).

В дашборде настроена отправка следующих целей:

- `section_view` — просмотр раздела;
- `section_navigation` — переход по навигации;
- `report_export` — нажатие кнопки выгрузки отчета;
- `territory_select` — выбор территории на карте;
- `scenario_select` — выбор сценария;
- `dashboard_filter` — изменение фильтра;
- `resource_error` — ошибка загрузки основного ресурса.

Для проверки установки откройте production-сайт с параметром:

<https://dashboard-tumen-standart.vercel.app/?_ym_debug=2>

Затем проверьте счетчик в разделе **Настройка → Проверка счетчика** в Яндекс
Метрике. Блокировщики рекламы и расширения браузера могут препятствовать
загрузке счетчика.

Перед публикацией проверьте требования к уведомлению пользователей и обработке
персональных данных. Номер счетчика не является секретом и находится в HTML.

## Внешние сервисы

Подложка карты загружается с ArcGIS Online, поэтому для ее отображения нужен доступ браузера к внешнему сервису. Остальные основные библиотеки находятся в папке `lib/`.

## Важное замечание

Дашборд публикуется как открытый статический сайт. Все данные, включенные в файлы проекта и отображаемые на странице, доступны пользователям, имеющим ссылку на сайт. Не добавляйте в репозиторий конфиденциальные данные, персональные сведения, ключи или токены.
